ポートフォリオのブログを、管理画面や API ではなく **MDX ファイル**で運用する形に切り替えました。

## なぜ MDX か

初期のポートフォリオとしては、CMS・DB・認証付き管理画面は重すぎました。記事はリポジトリ内の `.mdx` を編集してデプロイするだけで十分です。

## 使い方

1. `posts/` に `.mdx` を追加する
2. frontmatter に `title` / `summary` / `publishedAt` を書く
3. 下書きは `draft: true` を付ける

```ts
// 例: frontmatter
{
  title: 'Hello MDX',
  summary: '...',
  publishedAt: '2026-07-23',
}
```

あとは push して再デプロイすれば公開されます。
